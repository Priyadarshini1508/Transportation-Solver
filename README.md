Step 1: Get the Code
Open CMD (Command Prompt), go to your Desktop, and run:

DOS
git clone https://github.com/Priyadarshini1508/Transportation-Solver.git
cd Transportation-Solver
☕ Step 2: Run the Backend (IntelliJ)
Open IntelliJ IDEA.

Click File > Open and select the folder: transportation-model.

Wait for the progress bar at the bottom to finish (Loading Maven).

Open TransportationModelApplication.java and click the Green Play Button.

Keep this running! It is the "Brain" of the project.

⚛️ Step 3: Run the Frontend (VS Code)
Open VS Code.

Click File > Open Folder and select: major_project_frontend/transportation-frontend.

Open the terminal in VS Code (Ctrl + ~) and type these two commands:

Bash
npm install
npm run dev
Click the link that appears (usually http://localhost:5173).
